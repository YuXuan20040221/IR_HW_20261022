# Information Retrieval Assignment (2026/10/22)

用 1.5 GB 維基百科，數出一個語言模型

## 步驟

1. 把語料裡的詞與相鄰詞對數出來。
   a. 讀取文章
   b. 斷詞
   c. 計算詞語出現次數
2. 用次數算機率，做出會預測、會生成的模型。  
   公式：$P(w_2 | w_1)　=　count(w_1, w_2) ／ count(w_1)$
3. 觀察它會什麼、不會什麼。(完成下面問題)

## 所需功能

- 預測 `predict(w, k)`：給一個詞，列出最可能接在後面的前 k 個詞與機率。
- 評分 `prob(sentence)`：回傳整句的 log 機率：把每一組相鄰詞的 log P 加起來。
- 生成 `generate(seed, n)`：從 seed 接龍 n 個詞。取機率最高、依機率抽樣，兩種都要。

## 用模型回答五個問題

### 1 貪婪 vs. 抽樣　每次都取機率最高的詞，會生成什麼？會不會繞圈？

以程式為例：
同樣輸入「台灣」

- 用貪婪的方式抽取最大值的文字，輸出結果容易繞圈  
  `台灣北部，是在《》，是在《》，是在《`

- 用抽樣的，因為每次抽取的是不一樣的詞，比較不容易形成無限循環  
  `台灣交流。後，上映。眾多，全年的時段香港跳舞時。`

雖然生出來的東西都沒什麼邏輯......

## 觀察與發現

從實驗結果來看，因為我沒有把 "，" 、 "。" 之類的標點符號從字典中去除，所以接在一個字後面的字是標點符號的機率往往是最高的，這會變成生出來的句子常常會是斷斷續續的，然而，一般人使用句子並不會像這樣不斷用逗號斷句。若是把符號去掉，又會使得句子難以閱讀，所以或許還有其他可以處理這樣現象的方法(讓標點符號出現又不要那麼頻繁出現)，只是我目前沒想到。
